# Domain Docs

This repository has a single domain context.

Before exploratory engineering work, read the root `CONTEXT.md` if it exists and any relevant records in `docs/adr/`. If either is absent, proceed without flagging its absence.

Use terminology defined in `CONTEXT.md`; if no glossary exists, prefer terms established by the affected code and feature documentation. Surface conflicts with an existing ADR rather than silently overriding it.
