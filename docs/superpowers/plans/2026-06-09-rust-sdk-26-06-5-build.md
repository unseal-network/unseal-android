# Rust SDK 26.06.5 Runnable Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Android Matrix Rust SDK dependency with the verified `26.06.5` artifact and produce a debug APK that can be installed and used for real testing.

**Architecture:** Keep the existing Element X Matrix wrapper code and Gradle module layout intact. Change only the Rust SDK artifact coordinate/version first, then let compiler errors identify any required FFI API compatibility edits. Verify the downloaded AAR by size and SHA-256 before claiming the app uses the requested artifact.

**Tech Stack:** Gradle version catalog, Maven Central, Android Gradle Plugin, Kotlin, Matrix Rust Components Kotlin AAR, existing `:libraries:matrix:impl` wrapper, debug APK build.

